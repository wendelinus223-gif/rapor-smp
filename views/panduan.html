Panduan Penggunaan Aplikasi Rapor SMP

Petunjuk langkah demi langkah untuk mengoperasikan sistem Rapor SMP Multi-Sekolah & Multi-Role Wali Kelas.

1. Akses Multi-Sekolah & Peran Pengguna

  • Registrasi Sekolah: Klik "+ Daftarkan Sekolah Baru" di modal login, masukkan NPSN unik, Nama Sekolah, dan Password Admin.
  • Akun Admin Sekolah: Login menggunakan NPSN Sekolah. Admin memiliki akses penuh ke seluruh kelas, data identitas sekolah, pengaturan password wali kelas, serta pencetakan dokumen resmi.
  • Akun Wali Kelas: Login menggunakan format NPSN-KELAS (contoh: 50102030-IX) dan password yang dibuatkan Admin. Tampilan otomatis terkunci hanya pada kelas yang diampu (VII, VIII, atau IX).
  • Isolasi Database: Setiap sekolah terisolasi dalam memori lokal, sehingga data antar-sekolah tidak akan saling bercampur.

2. Dashboard & Monitoring

  • Ringkasan Sesuai Peran: Admin melihat total seluruh siswa sekolah, sedangkan Wali Kelas fokus memantau statistik total siswa di kelasnya.
  • Distribusi Predikat: Memantau pencapaian nilai (Predikat A, B, C, D, E) seluruh mata pelajaran secara grafik visual.
  • Kelengkapan Rapor: Indikator persentase untuk memastikan seluruh komponen nilai siswa telah terisi penuh 100%.

3. Kelola Siswa & Akun Wali Kelas

  • Atur Password Wali: Pada menu Kelola Wali Kelas, Admin dapat menyesuaikan Nama, NIP, serta menentukan Password login untuk tiap Wali Kelas (VII, VIII, IX).
  • Input & Impor Biodata CSV: Tambah/Edit data siswa dapat dilakukan secara manual atau impor masal melalui file template CSV.
  • Peringkat Otomatis: Peringkat akademis dihitung secara otomatis berdasarkan akumulasi total nilai rata-rata tiap siswa di kelasnya.

4. Kalkulator Nilai & Hak Cetak

  • Komponen Nilai: Guru mengisikan Nilai Ulangan Harian (UH1, UH2, UH3), UTS (MID), dan UAS per mata pelajaran Kelompok A dan B.
  • Rata-Rata Rapor Otomatis: Nilai Akhir Rapor dihitung secara otomatis dari kalkulasi akumulasi komponen nilai tanpa perlu diketik manual.
  • Deskripsi & Predikat Otomatis: Predikat (A-E), Capaian Kompetensi, dan Rekomendasi Deskripsi langsung tergenerasi otomatis.
  • Pusat Hak Cetak: Demi keamanan dan validasi berkas, cetak Rapor F4, Sampul, & Lembar Identitas dipusatkan khusus pada Akun Admin Sekolah.

5. Transisi Tahun Ajaran & Kenaikan Kelas Masal

  • Fitur Khusus Admin: Buka menu Pulihkan/Backup Data dan klik "Jalankan Proses Kenaikan Kelas Masal" saat pergantian tahun ajaran.
  • Auto-Backup Arsip: Sistem mengunduh file cadangan JSON riwayat tahun lalu secara otomatis sebelum mutasi berjalan.
  • Promosi & Kelulusan: Siswa Kelas VII dan VIII otomatis naik tingkat (VII→VIII, VIII→IX). Siswa Kelas IX dinyatakan Lulus dan dikeluarkan dari daftar siswa aktif.
  • Reset Nilai: Tahun Ajaran bertambah otomatis (misal 2026/2027 → 2027/2028), Semester diatur ke Ganjil, dan database nilai dibersihkan untuk penginputan periode baru.

6. Pemeliharaan & Backup Data

Data tersimpan secara lokal di peramban (localStorage). Pastikan Admin Sekolah melakukan Download Backup JSON secara berkala agar data tetap aman jika komputer atau peramban dibersihkan.
