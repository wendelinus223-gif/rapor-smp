Backup & Restore Data Aplikasi SMP

Cadangkan Data (Backup)

Unduh seluruh data aplikasi (Siswa, Sekolah, Wali, Nilai) ke dalam file JSON untuk mengamankan data.

Pulihkan Data (Restore)

Unggah file JSON backup untuk mengembalikan seluruh data aplikasi.

Proses Kenaikan Kelas Masal (Tahun Ajaran Baru)

Naikkan seluruh tingkat kelas siswa secara otomatis & arsipkan siswa Kelas IX yang Lulus.

Perhatian Sebelum Memproses:
  • Sistem akan otomatis mengunduh file cadangan (Backup JSON) untuk mengarsipkan riwayat rapor tahun ajaran ini.
  • Siswa Kelas VII dan VIII akan dinaikkan 1 tingkat kelas secara otomatis (VII → VIII, VIII → IX).
  • Siswa Kelas IX akan otomatis dinyatakan Lulus dan dikeluarkan dari daftar aktif.
  • Data nilai mata pelajaran akan di-reset agar bersih untuk input nilai Tahun Ajaran baru.
